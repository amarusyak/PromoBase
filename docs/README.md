# PromoBase documentation

| File                                                                                                 | What it is                                                                                                                                                                                     |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [PromoBase_Product_Requirements_Document_v0.3.pdf](PromoBase_Product_Requirements_Document_v0.3.pdf) | The entry PRD, v0.3 (8 October 2026). Requirements are numbered PB-001 to PB-015. It is not revised during development (D-065).                                                                |
| [decisions.md](decisions.md)                                                                         | The decisions log, D-001 onwards: a published copy of the working log, updated in every pull request that adds or changes a decision. It amends the PRD: where the two disagree, the log wins. |

Commits, pull requests and test names refer to these IDs, for example `PB-007` or `D-100`.

When the scope of v0.3 is built, a v0.4 "resulting PRD" is written from v0.3 and the log: dropped items struck through, what was built as agreed along the way marked (D-065). It goes here next to v0.3, which stays as it is.
